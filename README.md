# На все котировки

Оригинальная сатирическая браузерная 3D-игра о карьере биржевого брокера: переговоры с клиентами под давлением времени, анализ вымышленных компаний, экономика и постепенное создание финансовой империи.

## Концепция
Игрок начинает в комнате общежития, работает за старым компьютером, изучает рынок и разговаривает с клиентами. Ответы влияют на доверие, терпение и вероятность сделки. По мере развития игрок улучшает жильё, открывает офис и нанимает команду.

## Статус
Сейчас фиксируется концепция и создаётся основа документации. Не считайте игровые функции реализованными, пока это не подтверждено кодом и тестированием.

## Важные принципы
- Интерфейс — часть игрового мира, а не обычный финансовый дашборд.
- Все компании и показатели вымышлены.
- Сначала создаём небольшой качественный вертикальный срез, затем расширяем игру.
- Первый прототип должен работать без обязательного платного ИИ.
- Все крупные изменения должны быть проверяемыми и сохранять существующие материалы.
